Matrizes e dimensões

Organizar observações em matrizes e executar produtos com dimensões justificadas.

Pré-requisitos: M01: vetores, componentes, produto escalar e previsão linear.

Primeiro, a ideia

Uma matriz é uma tabela retangular de números. Em aprendizagem, usamos frequentemente uma linha por observação e uma coluna por característica. Três páginas e duas características dão dimensão 3×2, também chamada shape.

Multiplicar X por um vetor w aplica o produto escalar de cada linha ao mesmo vetor. Se X tem n linhas e d colunas, w precisa de d elementos. A saída tem n previsões. Escrever as dimensões antes da conta evita muitos erros.

A transposta troca linhas por colunas: 3×2 passa a 2×3. Transpor não é inverter. O produto matricial não permite trocar livremente a ordem: AB e BA podem ter dimensões diferentes, ou um deles nem existir.

X: n×d; w: d×1; Xw: n×1

1. Uma matriz organiza números em linhas e colunas

Uma matriz é uma tabela retangular de números. Escrevemos X com letra maiúscula e dizemos que tem dimensão, ou shape, número de linhas × número de colunas. A matriz abaixo tem duas linhas e três colunas, portanto shape 2×3.

X = [[1, 2, 3], [4, 5, 6]]   →   shape 2×3

Em dados de Machine Learning, uma convenção frequente é uma observação por linha e uma característica por coluna. O contrato tem de ser explícito; uma biblioteca não sabe que a primeira coluna representa imagens.

Matriz X de duas páginas e três características
ObservaçãoImagensScriptsTamanho (MB)
Página A321,5
Página B140,8

A matriz numérica é [[3,2,1,5],[1,4,0,8]] quando usamos vírgula decimal na escrita portuguesa; em Python, escrevemos 1.5 e 0.8. Tem n=2 observações e d=3 características, logo shape n×d=2×3.

O elemento Xᵢⱼ está na linha i e coluna j. Os índices matemáticos desta aula começam em 1: X₂₃=0,8. Em NumPy, os índices começam em 0, por isso o mesmo elemento é X[1,2]. Distingue convenção matemática de sintaxe de código.

Uma matriz precisa de linhas do mesmo comprimento. [[1,2],[3]] não é uma matriz retangular 2×2. NumPy moderno pode rejeitar a criação como array numérico regular ou criar estruturas inadequadas se forçares um tipo de objetos; corrige os dados em vez de esconder o problema.

2. Igualdade, adição e multiplicação por escalar

Duas matrizes são iguais quando têm a mesma shape e todos os elementos correspondentes são iguais. Uma matriz 2×3 nunca é igual a uma 3×2, mesmo que tenha os mesmos seis números.

A adição exige a mesma shape e atua elemento a elemento. Se A=[[1,2],[3,4]] e B=[[5,6],[7,8]], então A+B=[[6,8],[10,12]]. Pensa em sobrepor as tabelas: cada célula encontra exatamente uma célula correspondente.

Subtração segue a mesma regra. A−B é diferente de B−A; os resultados são opostos. A matriz zero, com zeros em todas as posições, é o elemento neutro da adição.

Multiplicar por um escalar multiplica todas as células. Para 2A, obténs [[2,4],[6,8]]. Não altera a shape. Em dados, converter segundos para milissegundos pode ser multiplicar uma coluna por 1000, mas não deves multiplicar colunas com outras unidades.

A expressão A*B em NumPy multiplica elementos correspondentes, sujeita às regras de broadcasting. Não representa, em geral, o produto matricial desta aula. Por exemplo, se A e B forem 2×2, A*B produz [[5,12],[21,32]].

3. Transpor troca linhas por colunas

A transposta de X escreve-se Xᵀ. A primeira linha torna-se a primeira coluna, a segunda linha torna-se a segunda coluna, e assim sucessivamente.

[[1, 2, 3], [4, 5, 6]]ᵀ = [[1, 4], [2, 5], [3, 6]]

A shape passa de 2×3 para 3×2. O elemento que estava em Xᵢⱼ passa para a posição j,i. Transpor duas vezes recupera a matriz original: (Xᵀ)ᵀ=X.

Transpor não significa inverter uma matriz. Uma inversa é outra operação, só existe para certas matrizes quadradas e será estudada mais tarde. Xᵀ existe para qualquer matriz retangular.

Em dados, Xᵀ coloca características nas linhas e observações nas colunas. Isto pode ser útil numa fórmula, mas não altera o contrato conceptual: tens de saber qual orientação cada operação espera.

4. Produto matriz-vetor: várias previsões de uma vez

Se X tem shape n×d e w tem d componentes, Xw está definido e produz n valores. Cada linha de X faz um produto escalar com w. A dimensão interior d tem de coincidir.

Usa X=[[1,2],[3,0]] e w=[10,20]. X tem shape 2×2 e w tem dimensão 2. Para a primeira saída, faz [1,2]·[10,20]=1×10+2×20=50. Para a segunda, [3,0]·[10,20]=3×10+0×20=30. Portanto Xw=[50,30].

Produto linha a linha
Linha de XProduto com wSaída
[1,2]1×10+2×2050
[3,0]3×10+0×2030

Para uma previsão linear, adiciona o mesmo viés b a cada saída: Xw+b. Com b=5, tens [55,35]. Conceptualmente, b é um escalar aplicado às n previsões. NumPy usa broadcasting para essa adição.

Uma matriz 4×3 aceita um vetor de três pesos e devolve quatro previsões. Não aceita um vetor de quatro pesos nesta orientação: o número de pesos corresponde às colunas, não às linhas.

Se precisares de duas saídas por observação, por exemplo duas pontuações, substituis o vetor w por uma matriz de pesos W com shape d×2. Então XW terá shape n×2. Esta é a ponte para o produto matriz-matriz.

5. Produto matricial: linha por coluna

O produto AB está definido quando o número de colunas de A coincide com o número de linhas de B. Se A tem shape m×n e B tem shape n×p, o resultado C=AB tem shape m×p. As dimensões interiores n coincidem; as exteriores m e p formam a saída.

(m×n) @ (n×p) → (m×p)

Cada célula Cᵢⱼ é o produto escalar da linha i de A com a coluna j de B. Considera A=[[1,2],[3,4]], shape 2×2, e B=[[5,6],[7,8]], também 2×2:

Cálculo de C=AB
CélulaLinha por colunaValor
C₁₁[1,2]·[5,7]1×5+2×7=19
C₁₂[1,2]·[6,8]1×6+2×8=22
C₂₁[3,4]·[5,7]3×5+4×7=43
C₂₂[3,4]·[6,8]3×6+4×8=50

Logo AB=[[19,22],[43,50]]. O produto BA também está definido neste caso, mas dá [[23,34],[31,46]]. Em geral, AB≠BA: produto matricial não é comutativo.

Uma matriz 4×3 pode multiplicar uma 3×2, produzindo 4×2. A ordem inversa, 3×2 vezes 4×3, não está definida porque 2≠4. Não tentes resolver a incompatibilidade transpondo ao acaso: isso muda a operação e o significado.

O produto é associativo quando as dimensões permitem: (AB)C=A(BC). Também distribui sobre a adição. A ordem dos fatores continua fixa. Estas propriedades permitem organizar uma cadeia de transformações de formas computacionalmente diferentes sem alterar o resultado matemático.

6. Matrizes como transformações

Uma matriz 2×2 pode transformar um vetor do plano. A matriz identidade I=[[1,0],[0,1]] mantém qualquer vetor: Iv=v. A primeira saída copia a primeira componente e a segunda copia a segunda.

A matriz S=[[2,0],[0,3]] transforma [x,y] em [2x,3y]: estica a direção horizontal por 2 e a vertical por 3. Para v=[1,2], Sv=[2,6]. Esta interpretação liga o produto a transformações visuais que conheces de gráficos e interfaces.

A matriz R=[[0,−1],[1,0]] transforma [x,y] em [−y,x], uma rotação de 90° no sentido anti-horário. Para [2,1], Rv=[−1,2]. Podes confirmar que a norma se mantém: √5 antes e depois.

Duas transformações sucessivas correspondem a um produto matricial. Se aplicas primeiro S e depois R, obténs R(Sv)=(RS)v. A matriz mais próxima do vetor atua primeiro. Trocar RS por SR pode mudar o resultado, tal como a ordem de funções compostas em B03.

Uma matriz que envia direções diferentes para o mesmo resultado perde informação. Nem toda a transformação pode ser desfeita por uma matriz inversa. Nesta aula basta reconhecer a possibilidade; determinantes e inversas ficam para aprofundamento.

7. Traduzir a notação para NumPy

NumPy representa vetores e matrizes com arrays. shape informa as dimensões; dtype informa o tipo dos elementos. Confirma ambas quando os resultados surpreendem.

import numpy as np

X = np.array([[1., 2.], [3., 0.]])
w = np.array([10., 20.])
print(X.shape)       # (2, 2)
print(w.shape)       # (2,)
print(X @ w)         # [50. 30.]
print(X * X)         # produto elemento a elemento
print(X.T)           # transposta

Um vetor com shape (2,) não mostra orientação de linha ou coluna. Um array [[10],[20]] tem shape (2,1). Em certas operações, os resultados diferem. Para previsões e alvos, verifica shapes exatas em vez de confiar que broadcasting fará o pretendido.

Broadcasting permite operar arrays de shapes compatíveis sem copiar explicitamente valores. Somar um escalar 5 a [50,30] dá [55,35]. Somar um vetor de duas colunas a uma matriz 3×2 aplica esse vetor a cada linha. É útil, mas pode esconder erros.

Exemplo perigoso: previsões com shape (3,1) menos alvos com shape (3,) pode produzir shape (3,3), comparando cada previsão com todos os alvos. O código corre, mas calcula nove erros. Se queres três diferenças, usa shapes iguais, como (3,) e (3,), ou (3,1) e (3,1).

EXEMPLO RESOLVIDO A

Duas páginas

X tem linhas [1,2] e [3,0]; w=[10,20]. Primeira previsão: 1×10+2×20=50. Segunda: 3×10+0×20=30. A saída é [50,30]. Somar b=5 a cada elemento dá [55,35].

EXEMPLO RESOLVIDO B

Dimensões primeiro

(4×3) vezes (3×2) é possível: as dimensões interiores coincidem. O resultado tem as exteriores, 4×2. (4×3) vezes (4×2) não é possível nesta ordem.

Um erro a evitar

Em NumPy, * multiplica elementos e @ faz produto matricial. Uma operação pode executar e representar a conta errada.

Da ideia ao código

Python · executa num ficheiro .py; blocos comentados são esquemas e estão identificados como tal.

import numpy as np

X = np.array([[1., 2.], [3., 0.]])
w = np.array([10., 20.])
previsoes = X @ w + 5
assert X.shape == (2, 2)
assert w.shape == (2,)
assert previsoes.shape == (2,)
assert np.allclose(previsoes, [55., 35.])
print({"shape": X.shape, "previsoes": previsoes.tolist()})
