AULA B02 · 2 sessões de 60 minutos

Álgebra sem saltos

Isolar uma incógnita e interpretar pesos numa expressão.

Pré-requisitos: B01: sinais e divisão.

Primeiro, a ideia

Uma variável guarda um valor que pode mudar. Em matemática, x pode representar o número de imagens numa página. Um coeficiente é um multiplicador: em 3x, o 3 multiplica x. Escrever 3x é escrever 3 × x; não é um nome de variável como em JavaScript.

Uma equação afirma que duas expressões têm o mesmo valor. Para descobrir x, mantém a igualdade: uma operação feita num lado tem de ser feita no outro. Não precisas de decorar “passa para o outro lado”; pensa em retirar a mesma quantidade aos dois pratos de uma balança.

Um modelo linear combina uma parte variável com uma parte fixa. Em y = wx + b, x é a entrada, w o peso ou declive, b o valor de base e y a saída. Aprender um modelo será escolher w e b a partir de dados. Nesta aula apenas calculamos com valores conhecidos.

y = w × x + b

1. Ler álgebra como uma linguagem

Uma expressão representa uma quantidade: 3x + 2. Uma equação afirma uma igualdade: 3x + 2 = 14. A expressão, sozinha, não é uma pergunta com uma solução. A equação permite procurar os valores de x que tornam a igualdade verdadeira.

Uma variável é um símbolo cujo valor pode variar no contexto. Uma incógnita é a variável cujo valor estás a procurar. Uma constante mantém-se fixa nesse problema. Em 3x + 2, os termos são 3x e 2; o coeficiente de x é 3. Em −x, o coeficiente é −1, porque −x = (−1) × x.

Em matemática, 3x significa 3 × x, e xy significa x × y. Em JavaScript escreves 3 * x e x * y. Não confundas o símbolo da variável x com o sinal de multiplicação ×. Uma igualdade matemática não é uma atribuição de código: x = x + 1 não tem solução nos números reais, mas x = x + 1 em JavaScript pode atualizar a variável.

Nos exemplos desta aula trabalhamos inicialmente com números reais: incluem inteiros, frações e outros números como a raiz quadrada de 2. Um problema pode restringir as soluções, por exemplo a contagens inteiras não negativas.

2. Substituir antes de calcular

Para avaliar uma expressão, troca todas as ocorrências da variável pelo seu valor. Usa parênteses quando o valor é negativo. Em 3x + 2 para x = −4: 3 × (−4) + 2 = −12 + 2 = −10. Não transformes 3x em 3 + x.

Em x² − 2x, para x = −3: (−3)² − 2 × (−3) = 9 − (−6) = 9 + 6 = 15. Primeiro substituímos, depois respeitamos a prioridade das operações. A mesma letra tem o mesmo valor em todas as posições durante esse cálculo.

Substituição também verifica respostas. Se suspeitas que x = 4 resolve 3x + 2 = 14, o membro esquerdo dá 3 × 4 + 2 = 14; o direito já é 14. Como coincidem, 4 é solução.

3. Mudar a forma sem mudar a quantidade

Juntar termos semelhantes

3x + 2x são três grupos de x mais dois grupos de x: cinco grupos, ou 5x. Em 3x + 2 − x + 5, junta 3x − x = 2x e 2 + 5 = 7; obténs 2x + 7. Os sinais pertencem aos termos: o termo −x tem coeficiente −1.

3x + 2 não se simplifica para 5x: o 2 não é multiplicado por x. E x² + x não é 2x², porque x² e x são tipos de termos diferentes. Experimenta x = 3: x² + x = 12, mas 2x² = 18.

Distribuir um multiplicador

A propriedade distributiva diz que a(b + c) = ab + ac. Em 2(x + 3), multiplica os dois termos: 2x + 6. Em −2(x − 3), temos (−2) × x + (−2) × (−3) = −2x + 6.

Um sinal menos antes de parênteses representa multiplicação por −1: −(x − 3) = −x + 3. Por exemplo, 5 − (2x − 1) = 5 − 2x + 1 = 6 − 2x. Escrever uma linha por transformação evita perder um sinal.

Colocar um fator comum em evidência

Fatorizar é escrever como produto. O caminho inverso de distribuir dá 6x + 9 = 3(2x + 3): ambos os termos tinham o fator 3. Verifica distribuindo de novo: 3 × 2x + 3 × 3 = 6x + 9.

Não “cortes” números através de uma soma. Em (2x + 6)/2, divide ambos os termos: 2x/2 + 6/2 = x + 3. Não fica x + 6. Uma simplificação deve preservar o valor da expressão inteira.

4. Resolver uma equação sem truques de sinais

Os membros são as expressões à esquerda e à direita de =. Imagina uma balança equilibrada: retirar o mesmo peso dos dois lados mantém o equilíbrio. Podemos somar ou subtrair a mesma quantidade aos dois membros. Podemos multiplicar ou dividir ambos pelo mesmo número não nulo.

Resolve 3x + 2 = 14:

  1. Subtrai 2 aos dois membros: 3x + 2 − 2 = 14 − 2.
  2. Simplifica: 3x = 12.
  3. Divide ambos por 3: 3x/3 = 12/3.
  4. Simplifica: x = 4.
  5. Verifica na equação original: 3 × 4 + 2 = 14.

O atalho “o 2 passa para o outro lado a subtrair” esconde a primeira operação. Enquanto aprendes, escreve os dois membros. Não precisas de decorar regras diferentes para cada lado.

Com coeficiente negativo: −2x + 5 = 11. Subtrai 5: −2x = 6. Divide por −2: x = −3. Verifica: −2 × (−3) + 5 = 6 + 5 = 11. O sinal do divisor importa.

5. Parênteses, dois membros e frações

Parênteses

Em 2(x + 3) = 14, podes dividir ambos os membros por 2: x + 3 = 7; depois subtrair 3: x = 4. Também podes distribuir primeiro: 2x + 6 = 14; subtrair 6: 2x = 8; dividir por 2: x = 4. Os caminhos são diferentes, a solução é a mesma.

Incógnita dos dois lados

Em 5x + 2 = 2x + 14, subtrai 2x de ambos os membros: 3x + 2 = 14. Subtrai 2: 3x = 12. Divide por 3: x = 4. Verifica os dois membros originais: 5 × 4 + 2 = 22 e 2 × 4 + 14 = 22.

Frações como divisões

Em x/3 + 2 = 5, subtrai 2: x/3 = 3. Multiplica ambos os membros por 3: x = 9. Verifica: 9/3 + 2 = 3 + 2 = 5.

Em (x − 1)/2 + x/3 = 4, os denominadores são 2 e 3. Multiplicar toda a equação por 6 elimina-os: 3(x − 1) + 2x = 24. Distribui: 3x − 3 + 2x = 24. Junta: 5x − 3 = 24. Soma 3: 5x = 27. Divide por 5: x = 27/5 = 5,4. Confirma: (5,4 − 1)/2 + 5,4/3 = 2,2 + 1,8 = 4.

O erro típico é multiplicar apenas as frações e esquecer o 4 do outro membro. Outra restrição: se existir uma variável no denominador, tens de excluir os valores que o tornam zero antes de transformar. Por exemplo, 1/(x − 2) exige x ≠ 2; o símbolo ≠ significa “diferente de”.

6. Nem toda a equação tem exatamente uma solução

Em 2x + 1 = 2x + 5, subtrair 2x dá 1 = 5. Esta afirmação é falsa, qualquer que seja x: não há solução. Não escrevas x = 0; substituir zero dá 1 = 5, ainda falso.

Em 2(x + 1) = 2x + 2, distribuir dá 2x + 2 = 2x + 2. Retirar os mesmos termos dá 0 = 0. É verdade para qualquer número real x: há infinitas soluções neste domínio. A transformação não disse que x é zero; eliminou a variável numa identidade.

Por isso não dividimos cegamente pelo coeficiente final se ele for zero. E multiplicar ambos os membros por zero não preserva as soluções: até uma igualdade falsa se torna 0 = 0. A verificação deve sempre regressar à equação original e ao domínio do problema.

7. Das palavras para uma fórmula

Segue quatro passos: define a incógnita e a unidade; escreve a relação; resolve com operações equivalentes; verifica a conta e o significado. Numa aplicação, x pode contar pedidos, e C representar custo em euros. Com 5 € fixos e 2 € por pedido, C = 5 + 2x.

Para C = 17: 17 = 5 + 2x; subtrai 5: 12 = 2x; divide por 2: x = 6 pedidos. Verificação: 5 + 2 × 6 = 17 €. Para C = 18, a equação dá x = 6,5. Se só admitimos pedidos inteiros, não há uma contagem que produza exatamente 18 € neste modelo.

Uma igualdade não é um limite

Se o orçamento for no máximo 18 €, a relação é 5 + 2x ≤ 18; ≤ significa “menor ou igual”. Daí x ≤ 6,5. Como x é inteiro não negativo, podes fazer de 0 a 6 pedidos. O máximo é 6. Se dividisses uma desigualdade por um número negativo, terias de inverter o sentido; o exemplo usa 2 positivo.

Rearranjar uma fórmula

Em y = wx + b, podes querer obter x a partir de y. Subtrai b: y − b = wx. Se w ≠ 0, divide por w: x = (y − b)/w. Os parênteses indicam que toda a diferença é dividida. Com y = 180, w = 20 e b = 100, tens x = (180 − 100)/20 = 4.

Se w = 0, a fórmula original fica y = b e deixa de depender de x. Não podes dividir por w. Se y e b forem iguais, qualquer x é compatível; se forem diferentes, nenhum é. Saber quando uma fórmula não se aplica faz parte de a compreender.

Antes de avançar

Explica a diferença entre simplificar uma expressão e resolver uma equação. Depois justifica por que subtrair a mesma quantidade nos dois membros preserva as soluções e por que não podes dividir por zero.

EXEMPLO RESOLVIDO A

Orçamento de carregamento

Cada imagem custa 20 ms e há 100 ms fixos. Para um total de 180 ms: 20x + 100 = 180. Subtrai 100 dos dois lados: 20x = 80. Divide ambos por 20: x = 4 imagens. Substitui para verificar: 20 × 4 + 100 = 180.

EXEMPLO RESOLVIDO B

Distribuir e simplificar

2(x + 3) = 14 equivale a 2x + 6 = 14. Subtrai 6: 2x = 8. Divide por 2: x = 4. Também podias dividir a equação inicial por 2: x + 3 = 7.

Um erro a evitar

2(x + 3) não é 2x + 3: o multiplicador aplica-se a cada termo dentro dos parênteses.

Da ideia ao código

JavaScript · consola do navegador

const prever = (x, w = 20, b = 100) => w * x + b;
console.log(prever(4)); // 180

01 / PRÁTICA

Muito fácil · Avalia 3x + 2 para x = −2.

Preciso de uma pista

Substitui x por (−2), depois multiplica.

Ver resolução

3 × (−2) + 2 = −6 + 2 = −4. Não somes 3 e −2 antes de multiplicar.

02 / PRÁTICA

Muito fácil · Simplifica 4x − x + 2x. Qual é o coeficiente final de x?

Preciso de uma pista

O termo −x tem coeficiente −1.

Ver resolução

4x − 1x + 2x = (4 − 1 + 2)x = 5x. O coeficiente é 5.

03 / PRÁTICA

Fácil · Resolve −2x + 5 = 11.

Preciso de uma pista

Subtrai 5 aos dois membros; divide pelo coeficiente com o seu sinal.

Ver resolução

−2x = 6. Divide por −2: x = −3. Verifica: −2 × (−3) + 5 = 11.

04 / PRÁTICA

Médio · Resolve 3(x − 2) + 4 = 13.

Preciso de uma pista

Distribui o 3 por ambos os termos dos parênteses.

Ver resolução

3x − 6 + 4 = 13; 3x − 2 = 13; 3x = 15; x = 5. Verificação: 3(5 − 2) + 4 = 9 + 4 = 13.

05 / PRÁTICA

Médio · Resolve 5x + 2 = 2x + 14.

Preciso de uma pista

Retira 2x dos dois membros e depois retira 2.

Ver resolução

3x + 2 = 14; 3x = 12; x = 4. Ambos os membros originais dão 22.

06 / PRÁTICA

Difícil · Resolve (x − 1)/2 + x/3 = 4.

Preciso de uma pista

Multiplica todos os termos da equação por 6.

Ver resolução

3(x − 1) + 2x = 24; 3x − 3 + 2x = 24; 5x = 27; x = 27/5 = 5,4. Verificação: 4,4/2 + 5,4/3 = 2,2 + 1,8 = 4.

07 / PRÁTICA

Desafiante · Um serviço A custa 8 € fixos + 2 € por pedido. B custa 2 € fixos + 3,5 € por pedido. Para quantos pedidos têm o mesmo custo?

Preciso de uma pista

Chama x à contagem e iguala os dois custos completos.

Ver resolução

8 + 2x = 2 + 3,5x. Subtrai 2 e 2x nos dois membros: 6 = 1,5x. Divide por 1,5: x = 4. A: 8 + 8 = 16 €. B: 2 + 14 = 16 €. A contagem é inteira e não negativa, logo faz sentido.

Aplicar e explicar

No papel, classifica e justifica: 2x + 1 = 2x + 5 (sem solução) e 2(x + 1) = 2x + 2 (todos os reais). Depois escreve o custo 5 + 2x e descobre o número máximo de pedidos inteiros para um orçamento de 18 €: 6 pedidos. Tapa as respostas na primeira tentativa. Explica a diferença entre custar exatamente 18 € e custar no máximo 18 €.
