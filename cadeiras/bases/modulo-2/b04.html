Médias, dispersão e amostras

Resumir dados sem esconder valores extremos nem confundir amostra com população.

Pré-requisitos: B01: frações.

Primeiro, a ideia

A média reparte a soma igualmente pelo número de observações. A mediana é o valor central depois de ordenar; com uma quantidade par de valores, é a média dos dois centrais. Ambas resumem o centro, mas respondem de forma diferente a valores extremos.

A dispersão descreve quanto os valores variam. A amplitude é máximo menos mínimo. A variância populacional faz a média dos quadrados das distâncias à média; o desvio padrão é a raiz quadrada da variância e recupera as unidades originais. Ao estimar variância populacional a partir de uma amostra, é habitual dividir por n−1; nesta aula descrevemos apenas o conjunto completo e dividimos por n.

Uma amostra é um subconjunto de uma população. Medir apenas o teu computador não representa todos os utilizadores. Mais dados do mesmo tipo não corrigem automaticamente a falta de dispositivos lentos. Antes de calcular, pergunta quem ficou de fora.

média = soma / n; amplitude = máximo − mínimo (n = número de valores)

Organiza as duas sessões

Primeira sessão: descrever os dados e calcular medidas de centro. Segunda: medir dispersão, analisar amostras e combinar grupos. Calcula à mão antes de usar código; mantém unidades junto dos resultados.

1. Uma observação precisa de contexto

Uma observação é um caso medido: por exemplo, um carregamento de página. Uma variável é a propriedade registada: latência, navegador ou ocorrência de erro. Uma linha pode reunir várias variáveis do mesmo carregamento. Não confundas número de linhas com número de utilizadores: uma pessoa pode gerar muitas linhas.

Uma variável quantitativa representa uma quantidade. Contagem de cliques é discreta, pois conta unidades; duração é tratada como contínua, embora o instrumento tenha resolução limitada. Uma variável categórica identifica grupos: navegador ou categoria do pedido. Codificar navegadores como 1,2,3 não torna significativa a média desses códigos.

Antes de resumir, pergunta: qual é a unidade? Como se mediu? Quando? Em que dispositivos? Um valor 0 pode ser uma medição válida, uma falha de instrumentação ou um valor introduzido para representar ausência. Não juntes esses casos sem uma regra documentada. Uma latência em segundos não pode entrar na mesma coluna que milissegundos sem conversão.

2. Contar e mostrar a distribuição

A frequência absoluta conta ocorrências. A relativa divide essa contagem pelo total. Para os cinco valores [100,100,120,120,300] ms, há dois valores 100, dois 120 e um 300. As frequências relativas são 2/5=0,4; 2/5=0,4; 1/5=0,2, ou 40%,40%,20%.

Para muitos valores, podes agrupá-los em intervalos, como [0,100), [100,200), [200,300). O símbolo [ inclui a fronteira esquerda; ) exclui a direita. Assim, 100 entra no segundo intervalo, não nos dois. Um histograma mostra frequências em intervalos numéricos; com intervalos de igual largura, as alturas podem representar contagens diretamente.

A distribuição mostra concentração, assimetria e valores afastados. Um resumo único perde essa forma. Um valor extremo não é automaticamente erro: pode ser o pedido lento que mais importa compreender.

3. Três perguntas diferentes sobre o centro

Média: repartir a soma igualmente

Para [100,110,390] ms, soma 100+110+390=600 ms e divide pelas três observações: 600/3=200 ms. A média é o valor que todos teriam se repartisses o total igualmente. Não precisa de coincidir com uma observação real.

A fórmula pode escrever-se média=(x₁+…+xₙ)/n. Cada x é uma observação, o índice indica a posição e n é a quantidade de observações. Se aparecer Σ, a letra grega sigma representa soma: Σxᵢ significa somar os valores indicados pelo índice. Primeiro compreende a lista de parcelas, depois a abreviatura.

Mediana: encontrar o centro da lista ordenada

Ordena os valores do menor para o maior. Em [390,100,110], a ordem é [100,110,390] e o central é 110. Com quantidade ímpar, escolhe a posição central; com quantidade par, calcula a média dos dois centrais. Em [2,4,8,10], a mediana é (4+8)/2=6, não 4 nem 8.

A mediana depende da ordem e das posições centrais. Se 390 passar a 3900, a mediana do exemplo de três valores continua a ser 110, mas a média sobe para (100+110+3900)/3=1370. Isto torna a mediana menos sensível a extremos; não significa que os extremos devam ser ignorados.

Moda: o valor mais frequente

Em [1,1,2,3], a moda é 1. Em [1,1,2,2,3], existem duas modas, 1 e 2. Quando todos os valores são distintos, é habitual dizer que não há moda informativa. Para categorias, a moda pode ser útil, ao contrário da média dos seus códigos.

Escolhe a medida pela pergunta. Para tempo típico numa distribuição com cauda lenta, mediana e distribuição são úteis. Para calcular tempo total a partir da quantidade, a média é útil: total=n×média. Reportar ambas pode revelar que a experiência típica e o consumo total contam histórias diferentes.

4. Quanto variam os dados?

As listas [5,5,5] e [1,5,9] têm média 5. Não têm o mesmo comportamento: a primeira é constante; a segunda varia muito. Precisamos de medidas de dispersão além do centro.

Amplitude

A amplitude é máximo menos mínimo. Na primeira lista: 5−5=0. Na segunda: 9−1=8. É simples, mas depende só dos extremos: não descreve como os valores interiores se distribuem.

Variância populacional, passo a passo

Vamos descrever o conjunto completo [2,4,6]. Primeiro calcula a média: (2+4+6)/3=4. Depois subtrai a média a cada valor. Esses desvios são −2,0,2. Somá-los daria zero, escondendo a dispersão; por isso elevamos cada desvio ao quadrado.

A variância populacional é a média desses quadrados: 8/3≈2,67. Se os valores estiverem em milissegundos, a variância está em ms². Mantém a fração 8/3 até ao fim, evitando arredondar cedo.

Desvio padrão

O desvio padrão é a raiz quadrada da variância: √(8/3)≈1,63 ms. Recupera as unidades originais. É uma medida do tamanho da dispersão, mas não é exatamente a média das distâncias absolutas. Não afirma que todos os pontos ficam a essa distância da média.

Para [5,5,5], todos os desvios são zero, logo variância e desvio padrão são zero. Uma variância não pode ser negativa, porque é uma média de quadrados não negativos.

Por que às vezes se divide por n−1?

Quando descrevemos todos os valores do conjunto como uma população, dividimos por n. Quando queremos estimar a variância de uma população a partir de uma amostra aleatória independente, usa-se frequentemente a variância amostral com divisor n−1. A média da própria amostra já foi estimada, e os desvios somam zero: um desvio fica determinado pelos restantes.

Nos mesmos [2,4,6], a variância amostral é 8/(3−1)=4 e o desvio padrão amostral é √4=2. A correção torna a estimativa da variância não enviesada sob as hipóteses usuais de amostragem independente com variância finita; não torna a amostra representativa nem corrige dados mal recolhidos. Para n=1, este cálculo amostral não está definido. Nesta aula, cada exercício indica qual o divisor pretendido.

5. População não é o ficheiro que tens à mão

A população é o conjunto sobre o qual queres concluir algo: por exemplo, todos os carregamentos de utilizadores reais nesta semana. A amostra é o subconjunto observado. Um parâmetro descreve a população; uma estatística é calculada na amostra para a descrever ou estimar um parâmetro.

Medir cem vezes no teu portátil não representa automaticamente telemóveis, redes lentas ou outros países. Repetição pode tornar a medição desse portátil mais estável, mas não acrescenta os grupos ausentes. Aumentar uma amostra enviesada não elimina o mecanismo que a tornou enviesada.

Também importa a independência. Cem carregamentos da mesma sessão podem estar relacionados por cache ou rede. Se os tratares como cem utilizadores independentes, podes exagerar a informação disponível. Regista utilizador/sessão quando for adequado e compara unidades coerentes.

Mesmo com boa amostragem, amostras diferentes dão médias diferentes. Essa variabilidade não significa necessariamente erro no código. Nesta fase, relata dimensão e contexto da amostra; mais tarde estudarás intervalos de confiança e inferência formal. Não confundas desvio padrão dos dados com incerteza da média: são perguntas diferentes.

6. Combinar grupos e interpretar com cuidado

Média ponderada

Um grupo tem 2 carregamentos e média 100 ms. Outro tem 8 e média 200 ms. A média das médias, (100+200)/2=150 ms, dá o mesmo peso aos grupos apesar de terem dimensões diferentes. Recupera os totais: 2×100=200 ms e 8×200=1600 ms. Soma: 1800 ms em 10 carregamentos. Média global=1800/10=180 ms.

A fórmula é (n₁m₁+n₂m₂)/(n₁+n₂), em que n representa contagem e m a média de cada grupo. Os pesos são as contagens. Só podes fazer a média simples das médias diretamente quando os grupos têm o mesmo tamanho, ou quando a pergunta quer deliberadamente igual peso por grupo.

Comparar condições semelhantes

Uma versão nova pode parecer mais rápida porque foi testada sobretudo em computadores potentes. Antes de atribuir a melhoria à versão, compara dispositivos, redes, horários e tarefas. Uma associação entre duas variáveis não prova que uma causou a outra; pode haver uma terceira variável a influenciar ambas.

Um pequeno relatório útil diz: o que mediste, quantos casos, unidades, média, mediana, dispersão, valores extremos e limitações. Não escrevas apenas “média 200”: 200 quê, sobre quantos casos e em que condições?

EXEMPLO RESOLVIDO A

Latências e um pedido lento

Para 100, 110 e 390 ms, a soma é 600 e a média é 600/3 = 200 ms. A mediana é 110 ms. A amplitude é 390−100 = 290 ms. A média de 200 não descreve um pedido típico tão bem como a mediana neste pequeno conjunto.

EXEMPLO RESOLVIDO B

Dispersão à mão

Para 2 e 4, a média é 3. Os desvios são −1 e 1; os quadrados são 1 e 1. A variância populacional é (1+1)/2 = 1. O desvio padrão é √1 = 1.

Um erro a evitar

Uma média baixa não garante ausência de pedidos muito lentos. Examina a distribuição e segmentos relevantes.

Da ideia ao código

JavaScript · consola do navegador

const xs = [2, 4, 6];
const media = xs.reduce((s, x) => s + x, 0) / xs.length;
const somaQuadrados = xs.reduce((s, x) => s + (x - media) ** 2, 0);
const varianciaPopulacional = somaQuadrados / xs.length;
console.log({ media, varianciaPopulacional, desvioPadrao: Math.sqrt(varianciaPopulacional) });
// Para mediana: ordenar NUMERICAMENTE, sem alterar o original.
const ordenados = [...xs].sort((a, b) => a - b);
const meio = Math.floor(ordenados.length / 2);
const mediana = ordenados.length % 2 ? ordenados[meio] : (ordenados[meio - 1] + ordenados[meio]) / 2;
console.log(mediana); // 4; este exemplo pressupõe lista não vazia.
