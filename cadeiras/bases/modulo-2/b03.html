Funções, gráficos e potências

Ler uma função como transformação e interpretar a inclinação.

Pré-requisitos: B02: variáveis e expressões.

Primeiro, a ideia

Uma função recebe uma entrada válida e devolve uma saída. Já fazes isto em código. O domínio é o conjunto de entradas permitidas: se x conta imagens, usar −3 pode não fazer sentido no contexto. A notação f(x) lê-se “f de x”, o valor da função na entrada x.

Num gráfico, a entrada costuma estar no eixo horizontal e a saída no vertical. Cada par (x, f(x)) é um ponto. O declive de uma reta é a variação vertical dividida pela variação horizontal. É uma taxa: milissegundos por imagem, por exemplo.

Uma potência representa multiplicação repetida: x² = x × x. Na função f(x) = x², a inclinação não é constante. Entre 1 e 2, a saída aumenta 3; entre 2 e 3, aumenta 5. Um logaritmo responde à pergunta inversa de uma potência: log₂(8) = 3 porque 2³ = 8. Vais voltar a esta ideia ao estudar perdas e probabilidades.

declive = (saída final − saída inicial) / (entrada final − entrada inicial)

1. Uma entrada, uma saída definida

Uma função associa a cada entrada permitida exatamente uma saída. A notação f(x) lê-se “f de x”. Em f(x) = 2x + 1, f é o nome da função, x é a entrada e 2x + 1 é a regra. Para x = 3: f(3) = 2 × 3 + 1 = 7. Não estamos a multiplicar f por x.

Em front-end, uma função que converte uma largura em tamanho de letra é uma analogia útil. Na função matemática aqui estudada, a mesma entrada tem sempre a mesma saída; não depende de estado escondido, hora atual ou chamadas aleatórias. Funções de programação podem ter esses comportamentos, por isso a analogia tem limites.

O domínio reúne as entradas permitidas. Se x conta imagens, pode ser {0,1,2,3,…}, o conjunto dos inteiros não negativos. Se x mede tempo, pode ser qualquer real não negativo. Os símbolos { } delimitam um conjunto; as reticências indicam continuação. Escrever x ≥ 0 significa “x maior ou igual a zero”.

O contradomínio é o conjunto de saídas declarado na definição. A imagem é o conjunto das saídas efetivamente obtidas. Se o domínio é {0,1,2}, o contradomínio é o conjunto dos reais e f(x)=2x+1, a imagem é {1,3,5}. O número 2 pertence ao contradomínio mas não à imagem deste exemplo.

Duas entradas podem dar a mesma saída: em f(x)=x², −2 e 2 dão 4. Continua a ser função. O que não pode acontecer é a mesma entrada ter duas saídas diferentes na mesma definição.

Quando uma entrada não serve

Na regra g(x)=1/(x−2), x=2 faria o denominador zero, por isso está excluído. Na regra h(x)=√x, quando trabalhamos com números reais, x não pode ser negativo. A raiz quadrada √x é o número não negativo cujo quadrado é x. Já num modelo de custo, uma entrada pode ser matematicamente calculável mas inválida no contexto: −3 pedidos não é uma contagem admissível.

2. Representar a mesma relação de três maneiras

Considera f(x)=20x+100, com x em imagens e f(x) em milissegundos. Para x=0, o valor é 100. Para x=1, é 120. Para x=2, é 140. A tabela lista as entradas e saídas; o gráfico coloca cada par como um ponto.

Um ponto (2,140) significa entrada 2 e saída 140. O eixo horizontal recebe a entrada; o vertical recebe a saída. A origem é (0,0). Uma divisão horizontal pode valer 1 imagem e uma vertical 100 ms: não compares comprimentos no papel sem ler as escalas.

Para ler f(2), começa em 2 no eixo horizontal, sobe até ao ponto ou curva e lê a altura no vertical. Para encontrar a entrada correspondente a 140 ms, faz o caminho inverso. Numa curva, uma mesma altura pode encontrar mais de uma entrada.

Um gráfico com eixo vertical cortado pode exagerar diferenças visualmente. Confirma limites, unidades e espaçamento dos eixos. Unir pontos é uma escolha: medições isoladas não provam o que acontece entre eles. O nosso segmento representa uma fórmula conhecida, não dados experimentais.

3. Uma reta tem taxa de variação constante

Uma função afim tem forma f(x)=mx+b. Aqui m é o declive: quanto a saída muda quando a entrada aumenta uma unidade. b é o valor para x=0, também chamado ordenada na origem. Em f(x)=20x+100, m=20 ms por imagem e b=100 ms.

Entre duas entradas distintas x₁ e x₂, a taxa média de variação é [f(x₂)−f(x₁)]/(x₂−x₁). Os índices 1 e 2 apenas identificam a primeira e a segunda entrada. Para 1 e 3 imagens: (160−120)/(3−1)=40/2=20 ms por imagem. A divisão não está definida se as duas entradas forem iguais.

Se m for positivo, a reta sobe; se for negativo, desce; se for zero, a saída é constante. Por exemplo, saldo(x)=50−5x perde 5 euros por utilização. Entre x=2 e x=4, os saldos são 40 e 30: (30−40)/(4−2)=−10/2=−5 euros por utilização.

Encontrar o zero

Um zero da função é uma entrada que dá saída zero. Em saldo(x)=50−5x, resolve 50−5x=0: subtrai 50, obtendo −5x=−50; divide por −5: x=10. Após dez utilizações, o saldo é zero. O zero é 10, não o número 0: estamos a pedir a entrada.

Uma reta pode prever valores fora do contexto útil. Após onze utilizações, o modelo de saldo dá −5 €. Isso só faz sentido se saldo negativo for permitido. E prolongar uma tendência para longe dos dados chama-se extrapolar: uma fórmula ajustada para páginas pequenas pode falhar em páginas enormes.

4. Potências e raízes sem confundir operações

Em 2³, 2 é a base e 3 é o expoente: 2 × 2 × 2 = 8. Para expoentes inteiros positivos, uma potência é uma multiplicação repetida. x² não é 2x: para x=3, dão 9 e 6. Se a base inteira é negativa, usa parênteses: (−2)²=4 e (−2)³=−8.

Multiplicar potências com a mesma base soma os expoentes: 2² × 2³ = (2×2)×(2×2×2)=2⁵. Dividir pela mesma base não nula subtrai-os: 2⁵/2²=2³. Uma potência elevada a outra multiplica expoentes: (2²)³=2⁶. Estas regras não autorizam somar expoentes numa adição: 2²+2³=4+8=12, não 2⁵.

Para uma base a não nula, a⁰=1. Um expoente negativo indica inverso: 2⁻³=1/2³=1/8=0,125. Uma raiz quadrada faz a operação inversa do quadrado com saída não negativa: √9=3. Mas resolver x²=9 dá x=3 ou x=−3, pois ambos têm quadrado 9. Distingue a função raiz da equação.

5. Linear, quadrático e exponencial

Compara, para x=0,1,2,3,4, as saídas de 2x, x² e 2ˣ. A primeira dá 0,2,4,6,8; a segunda 0,1,4,9,16; a terceira 1,2,4,8,16. Coincidir nalguns pontos não significa ser a mesma função.

Na linear 2x, somar 1 à entrada soma sempre 2 à saída. Na quadrática x², as diferenças entre saídas são 1,3,5,7: a taxa média muda. Na exponencial 2ˣ, somar 1 à entrada multiplica a saída por 2. Uma diferença constante sugere relação afim; um fator constante sugere relação exponencial, no modelo considerado.

O número de comparações entre pares pode crescer aproximadamente como o quadrado da quantidade de itens; duplicar a entrada quadruplica x². Um valor que aumenta 10% por etapa segue V(t)=V₀×1,1ᵗ: V₀ é o inicial e t conta etapas. De 100 passa a 110 e depois a 121, não a 120, porque a segunda percentagem incide em 110.

6. Perguntar pelo expoente e encadear funções

log₂(8)=3 significa “a que expoente elevamos 2 para obter 8?”. Como 2³=8, a resposta é 3. Em geral, logₐ(y)=x equivale a aˣ=y, com base a positiva e diferente de 1 e argumento y positivo. Não precisamos ainda de calcular logaritmos arbitrários: começa por potências conhecidas.

Se uma quantidade duplica em cada etapa e passa de 5 para 40, tens 5×2ᵗ=40. Divide ambos os membros por 5: 2ᵗ=8. Portanto t=3 etapas. O logaritmo ajuda a desfazer uma relação exponencial. Não é dividir 8 por 2.

Uma composição aplica uma função e depois outra. Define f(x)=2x+1 e g(y)=y². Então g(f(2)): primeiro f(2)=5; depois g(5)=25. A ordem contrária dá f(g(2))=f(4)=9. Em JavaScript, g(f(2)) também exprime essa ordem de avaliação.

Verifica a compatibilidade das entradas: se g só aceitar valores positivos, f(x) precisa de produzir um valor positivo antes de entrar em g. Compor não remove as restrições de domínio. Nas redes neuronais, vais encadear transformações deste modo.

EXEMPLO RESOLVIDO A

Uma reta de latência

f(x) = 20x + 100. Para x = 0, f(0) = 100. Para x = 2, f(2) = 140. Os pontos (0,100) e (2,140) dão declive (140−100)/(2−0) = 20 ms por imagem. O valor de base é 100 ms.

EXEMPLO RESOLVIDO B

Crescimento quadrático

Com f(x) = x², a tabela para x = 0,1,2,3 é 0,1,4,9. Duplicar x de 2 para 4 muda f(x) de 4 para 16: a saída quadruplica. Não confundas uma curva com uma reta só por ambas crescerem.

Um erro a evitar

f(x) não é f × x. É uma chamada de função. E x² não é 2x: para x = 3, dão 9 e 6.

Da ideia ao código

JavaScript · consola do navegador

const f = x => x ** 2;
console.table([0, 1, 2, 3].map(x => ({ x, y: f(x) })));

Muito fácil · Quanto vale 2³?

Preciso de uma pista

Ver resolução

2×2×2=8. Não é 2×3.

03 / PRÁTICA

Fácil · Para g(x)=1/(x−2), qual destas entradas está excluída?

Escolhe uma resposta

Preciso de uma pista

O denominador não pode ser zero.

Ver resolução

Em x=2, x−2=0. As outras entradas dão denominadores −2 e 1, que são permitidos.

04 / PRÁTICA

Médio · f(1)=10 e f(4)=22. Qual é a taxa média entre 1 e 4?

Preciso de uma pista

Divide a mudança da saída pela mudança da entrada.

Ver resolução

(22−10)/(4−1)=12/3=4 unidades de saída por unidade de entrada.

05 / PRÁTICA

Médio · Em saldo(x)=50−5x, qual é o zero da função?

Preciso de uma pista

Procura a entrada que faz a saída ser zero.

Ver resolução

50−5x=0; −5x=−50; x=10. Verificação: 50−5×10=0.

06 / PRÁTICA

Difícil · Uma quantidade começa em 5 e duplica por etapa. Após quantas etapas vale 40?

Preciso de uma pista

Divide 40 por 5 e procura a potência de 2.

Ver resolução

40/5=8; 2³=8; são 3 etapas: 5→10→20→40.

07 / PRÁTICA

Desafiante · f(x)=2x+1 e g(y)=y². Qual é a entrada não negativa x para g(f(x))=49?

Preciso de uma pista

A raiz de 49 é 7, mas considera também a alternativa −7 e a restrição x≥0.

Ver resolução

(2x+1)²=49 dá 2x+1=7 ou −7. A primeira dá x=3; a segunda x=−4, excluído pelo domínio. Verifica g(f(3))=g(7)=49.

Aplicar e explicar
